# Mystic Combat — Study, Architecture & Viva Documentation

Welcome to the team knowledge base for **Mystic Combat: Animeverse Incursion**.

This folder is designed as a **self-contained learning and preparation hub**. Whether you have never touched game development before, are coming from another engine like Godot, or are preparing for the hackathon project viva / jury presentation, everything you need to understand is documented here in plain language.

## 🎯 How to Use These Docs

1. **If you are new to game development:** Start with [**01. Unity for Beginners**](01_UNITY_FOR_BEGINNERS.md). It breaks down GameObjects, Components, Physics, and the Game Loop without jargon.
2. **If you need to explain the code to someone:** Read [**02. System Architecture**](02_ARCHITECTURE.md) and [**03. Feature Breakdown**](03_FEATURE_BREAKDOWN.md).
3. **Before speaking to judges / professors:** Rehearse with [**04. Viva & Interview Prep**](04_VIVA_AND_INTERVIEW_PREP.md).

These documents are continuously updated as new features and mechanics are built into the game.
